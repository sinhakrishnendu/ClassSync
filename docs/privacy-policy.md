# Privacy Policy

Temporary app name: ClassSync

## Summary

ClassSync is designed to work offline. Timetable data is stored locally on the user's device.

## Data Stored On Device

The app stores:

- selected Teacher or Administration workspace.
- courses, programmes, semesters, batches, and sections entered by the user.
- subject names and optional subject codes.
- class schedule entries.
- optional classroom, topic, teacher name, and notes.
- reminder settings.
- local app settings such as theme and time format.

## Data Not Collected

ClassSync does not collect:

- analytics data.
- advertising data.
- tracking identifiers.
- location.
- contacts.
- photos.
- camera data.
- microphone data.
- account credentials.
- institutional login data.

## Network Access

The app does not require internet access and does not request the internet permission. Android cloud backup is disabled for the app.

## Third-Party Services

The app does not use:

- Firebase Analytics.
- advertising SDKs.
- tracking SDKs.
- crash reporting services.
- cloud storage.
- remote sync services.

## Notifications

If reminders are enabled, ClassSync may request notification permission on Android versions that require it. Notification permission is used only to show class reminder notifications.

## Export And Import

If the user exports timetable data, the exported file is controlled by the user. The user is responsible for where they save or share it.

Imported data is validated locally before being stored.

## Delete Data

The app includes a delete-all-local-data option in Settings. This action requires explicit confirmation.
